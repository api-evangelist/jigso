# Jigso

> Jigso is a proactive AI operating system for enterprises that synthesizes data from across a company's business applications - CRM, support, communication, and data warehouses - into a unified, always-on intelligence layer. It continuously monitors connected systems to surface deal risks, churn signals, and action items, grounding every answer in verifiable business data. Capability is exposed through a REST API and an enterprise MCP (Model Context Protocol) platform. Jigso is SOC 2 Type II certified and GDPR compliant, and is backed by General Catalyst.

- [Jigso](https://www.jigso.io): Proactive AI operating system / always-on intelligence layer for enterprises.

## Developer
- [Jigso API](https://www.jigso.io/jigso-api): REST API to query organizational data, embed insights into dashboards/chatbots/internal apps, and trigger scheduled or event-driven queries. SOC 2 compliant with role-based permissions. Public developer documentation and OpenAPI are not published; access is arranged with Jigso.
- [MCP for Enterprise](https://www.jigso.io/mcp-for-enterprise): Enterprise MCP platform connecting internal tools (Gmail, Slack, Jira, HubSpot, Salesforce, Zendesk, Office 365, BigQuery, Snowflake) to AI assistants such as ChatGPT and Claude with permission-aware access.
